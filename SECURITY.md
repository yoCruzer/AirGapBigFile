# Security / 安全报告

Please do not publish vulnerability details in public Issues. Use
[GitHub Private Vulnerability Reporting](https://github.com/yoCruzer/AirGapBigFile/security/advisories/new)
to report a security vulnerability privately. Include reproduction steps and
only synthetic sample data; do not send credentials or personal files.

For ordinary bugs or compatibility problems, use
[public Issues](https://github.com/yoCruzer/AirGapBigFile/issues).

请勿在公开 Issue 中披露漏洞细节。请通过
[GitHub 私密漏洞报告](https://github.com/yoCruzer/AirGapBigFile/security/advisories/new)
私下提交安全问题，并提供复现步骤和合成测试数据；不要附带凭据或私人文件。
普通 bug 或兼容性问题可提交到
[公开 Issues](https://github.com/yoCruzer/AirGapBigFile/issues)。
